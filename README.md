# Starstead

Open-world life sim in top-down pixel art: farm, fish, build, work, race, rob, tame animals, then fly to the Moon and other planets. Single-player first.

Docs: docs/DESIGN.md (vision), docs/PLAN.md (roadmap), docs/RUNBOOK.md (how the automated hourly build works), docs/LOG.md (progress), docs/DEVIATIONS.md (anything off plan).
