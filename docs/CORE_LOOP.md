# Core loop (Phase 0 draft)

Minute to minute: walk, use a tool on a highlighted (yellow outline) target, collect, repeat.
Day to day: spend the 06:00-02:00 day on farm chores, fishing, gathering, jobs; sell in the evening; sleep saves.
Week to week: money buys tools, seeds, animals, building parts; build and upgrade the homestead; pay down the Vance debt.
Month to month: unlock the city (honest vs street rep), caves, vehicles, then the rocket seat and the Moon.
Every system feeds another: crops/animals/ore -> shop or crafting -> buildings/cars/weapons -> access to new jobs, sports and worlds.

Save: versioned JSON via GameState (user://save.json). Data lives in data/*.json for balancing.
